# Stage-Wise Reinforcement Learning for Robotic Manipulation

Static project webpage for Yu Zhang and Karl Mason, University of Galway.

## Preview locally

From this directory:

```bash
python -m http.server 8000
```

Open http://localhost:8000. No build or package installation is required.

## Edit

- `index.html`: project overview, author links, results and robot videos.
- `supplementary.html`: supplementary details with pre-rendered mathematical formulas.
- `style.css`: page styles.
- `assets/robot/`: CoppeliaSim and physical Dobot MG400 videos. Physical playback defaults to 8×.
- `static/katex/`: local math styles, fonts and KaTeX license.

Paper and Code buttons remain disabled until the camera-ready release.
Supplementary PDF and LaTeX files are not included.

## Hosting

This repository stores the webpage source and media. GitHub Pages and automatic
deployment are not enabled. The existing private Sites publication is managed separately.
